# Repository About

## Short Description

Report-first LLM security assessment framework for reproducible red-team suites, evidence packs, QA receipts, schemas, and archive verification.

## Long Description

FORGEDAN is an authorized LLM security assessment framework focused on producing auditable report deliverables. It combines evolutionary jailbreak testing, deterministic prompt/response scanners, Agent/MCP/tool-risk checks, source inventory tracking, JSON Schema contracts, QA handoff receipts, and post-copy archive verification so assessment teams can generate and review reproducible evidence packs.

This repository is not positioned as a commercial security platform. Its primary value is report quality: traceable evidence, reviewer sign-off, risk registers, redacted publication packs, historical comparison reports, and CI checks that protect the final handoff package.
